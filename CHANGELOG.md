# 🩸 BloodVeil RSPS - v1.3.0 Beta

## CHANGELOG

### Version 1.3.0 (February 18, 2026)

#### 🆕 New Features
- **Slayer Mastery System**
  - Choose specialization path at level 30 Slayer
  - Four distinct paths: Strength, Immunity, Recovery, Luck
  - Skill tree with 20 unlockable nodes (5 per path)
  - Respec system available at Slayer Masters
  - Persistent progression tracking

- **Enhanced UI**
  - Custom Slayer Mastery Tree interface
  - Improved interface positioning and scaling
  - Better responsive design for resizable mode

#### 🔧 Improvements
- Server stability enhancements
- Performance optimizations
- Memory management improvements
- Better error handling for item spawning

#### 🐛 Bug Fixes
- Fixed spawnitem command error handling
- Improved cache loading reliability
- Fixed various UI overlap issues
- Corrected configuration file loading

#### 🔨 Technical

- Java 11+ compatibility ensured
- Improved build process
